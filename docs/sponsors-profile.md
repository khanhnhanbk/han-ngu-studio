# GitHub Sponsors: setup checklist and profile text

Copy-paste text for https://github.com/sponsors/khanhnhanbk. Sponsorships are
**donations**: no tier promises a service, a feature or priority support.

## Setup (account owner only)

1. Turn on two-factor authentication: GitHub → Settings → Password and authentication.
2. https://github.com/sponsors → **Get sponsored** → choose the personal account →
   contact details → payout method **Bank account** → accept the terms → **Submit**.
3. Dashboard → **Stripe Connect account**: country of residence and bank account
   must both be **Vietnam**. Check every field before submitting.
4. Dashboard → Overview → tax form: **W-8BEN** (non-US individual). Vietnam has no
   income-tax treaty with the US, so leave the treaty section empty.
5. Dashboard → **Profile details**: paste the bio and introduction below, feature
   the repos listed below.
6. Dashboard → **Sponsor tiers**: create the tiers below (prices cannot be edited
   once published; retire and recreate to change).
7. Dashboard → **Request approval**. GitHub reviews it in a few days.

Tax: donation income may be taxable in Vietnam; ask a tax adviser once it is regular.
