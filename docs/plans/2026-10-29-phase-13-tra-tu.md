# Phase 13: "Tra từ" — meaning and part of speech (từ loại)

## Context

The owner wants learners to have one place to look up a word's meaning and part of speech, with Hanzii (screenshot of 亲戚) as the reference. Hán Ngữ Studio is a support tool, not a dictionary site, so the goal is a light lookup that feeds the other tools, not a Hanzii clone.

Today:
- Vietnamese meanings exist only for the ~11k HSK 3.0 words (`public/data/vocab.json`, from CVDICT via `scripts/build-vocab-source.mjs`). Other words show only the English CC-CEDICT line (`meanings.json`, 10k words) in the Đọc hiểu word card.
- **Part of speech is already in our source**: `hsk30-expanded.csv` (ivankra/hsk30, MIT, the GF 0025-2021 list) has a `POS` column (`N`, `V`, `Adj`, `Adv`, `M`, `Conj`, `Pron`/`Pr`, `Prep`, `Num`, `Aux`=trợ từ, `Suffix`, `Prefix`, `Intj`, `Name`, `Phonetic`; multi-POS as `V/N`). The build script reads the file but drops the column.
- **Classifiers (lượng từ)** are in CVDICT as `LT:門|门[men2],個|个[ge4],位[wei4]` (1561 entries); the build drops them too.
- Full CVDICT is 122k entries (10.8 MB raw), CC BY-SA 4.0, already credited.

### Decision on Hanzii

Do **not** embed Hanzii (iframe or scraped data). Reasons: HARD RULE 4 (every typed word would go to a third party on load), CLAUDE.md "never ship data scraped from other sites", and Hanzii's content and paywalled parts are theirs. Instead: an explicit **"Tra thêm trên Hanzii ↗"** link (new tab, `rel="noopener noreferrer"`), shown only after the user clicks it, the same pattern as the external tools listed in Giọng đọc. Add one line to HARD RULE 4 in `CLAUDE.md` for this link (only the clicked word goes, only on click). Optionally the same for MDBG / Wiktionary.

## What ships

1. Part of speech + Vietnamese meaning everywhere a word card exists (Đọc hiểu, Truyện đọc), plus a "Từ loại" field in Anki and a column in TSV exports.
2. A new page **"Tra từ"** (`/tools/tra-tu`, English "Word lookup" at `/en/tools/tra-tu`) in group "Từ vựng & ôn tập": one word or character in, one card out, with links into the other tools. No accounts, history only in the URL hash.
3. Đọc hiểu and Truyện đọc fall back to full CVDICT for words outside HSK, so a tap always shows a Vietnamese meaning when CVDICT has one.

## Work items

### 13a. POS + classifiers in the HSK data (S)

- `scripts/build-vocab-source.mjs`: add `pos` column (raw HSK code, `/`-separated) and `classifiers` column (from CVDICT `LT:` senses of the word's CEDICT keys, normalised to Simplified `门|个|位`, deduped). Re-run `pnpm build:vocab-source` (cached pinned files), then `pnpm build:data`.
- `buildVocab` in `scripts/build-data.mjs`: tuple becomes `[level, pinyin, meaning, pos, classifiers]`.
- `lib/vocab/lookup.ts`: `VocabInfo` gains `pos: PosCode[]` and `classifiers: string[]`, merged across matching entries like `meaning`. Keep old tuple consumers working (index access only).
- `lib/vocab/pos.ts`: `PosCode` union + labels via i18n (`vocab.pos.N` = "Danh từ" / "Noun", V Động từ, Adj Tính từ, Adv Phó từ, M Lượng từ, Conj Liên từ, Pron/Pr Đại từ, Prep Giới từ, Num Số từ, Aux Trợ từ, Suffix Hậu tố, Prefix Tiền tố, Intj Thán từ, Name Tên riêng, Phonetic Từ tượng thanh). Unknown code → shown raw, never dropped.
- Note honestly: POS is **per word**, not per sense. CVDICT senses have no POS, so we do not group senses under POS headings like Hanzii does. Phrases (1361 rows) have no POS → no badge.
- Tests in `lib/vocab/vocab.test.ts`: 爱 → `V`, 爱好 → `V`,`N`, 亲戚 → `N` + classifiers 门/个/位, 吧 → `Aux`.

### 13b. Full CVDICT shards (M)

- `buildCvdict` in `scripts/build-data.mjs` (source: CVDICT.u8 copied into `assets/dictionary/cvdict.u8` at the pinned commit, so the build is offline like the rest): shard by **first character** of the Simplified headword, FNV-1a hash into 64 shards `public/data/cvdict/<n>.json` (~170 KB raw each, check gzip). Row: `simp → [[trad, pinyin(tone marks), senses[], classifiers[]], …]`. Reuse the sense cleanup (pointer resolution, classifier split) from `build-vocab-source.mjs` by moving it to `scripts/lib/cvdict.mjs`.
- Sharding by first character means one shard also gives **"Từ bắt đầu bằng 亲"** (亲人, 亲戚, 亲切…) for free. Words containing the character elsewhere (串亲戚) are out of scope.
- `lib/cvdict/load.ts`: `cvdictFiles(word)`, `loadCvdictShard` with `memoJson`; `lookupCvdict(word, pinyin?)`. Goes into `sizes.json` automatically; one shard is far under the 2 MB prompt, but still call `confirmDownload`.
- Licence: same CVDICT (CC BY-SA 4.0); update `THIRD-PARTY-NOTICES.md` and `lib/legal/sources.ts` to say the full dictionary is shipped, share-alike applies to `public/data/cvdict/`.

### 13c. Word cards show POS (S)

- `components/reader/WordCard.tsx`: POS badges under the Pinyin line, classifier chips ("Lượng từ: 一门 / 一个 / 一位亲戚"), Vietnamese meaning from HSK data, else CVDICT shard, else English. "Xem đầy đủ" → `/tools/tra-tu#w=亲戚`.
- `lib/reader/analyze.ts`: carry `pos` and `classifiers` from `vocabFor`; CVDICT fallback loaded lazily on tap (not for the whole text), so the 95 % estimate and colouring stay unchanged.
- Anki (`lib/anki/`): add a `Từ loại` field to the note type and TSV column; update the 4 templates in `lib/anki/templates.ts` to show it small under Pinyin. Bump the note-type id only if the field list change requires it (check `apkg.ts`).
- Quiz: no change.

### 13d. "Tra từ" page (M)

Layout (top to bottom, Tailwind tokens, works in dark mode and Phồn thể):

1. Search box (word or single character; Phồn thể input goes through `conv.toSimp`). Hash `#w=` holds the query so it never reaches the server.
2. Header: word (shown script), Pinyin, Hán Việt (`lib/hanviet/`), HSK level badge, 🔊 (`SpeakButton`, if speech is on).
3. **Từ loại** badges + **Nghĩa** list (HSK/CVDICT senses, numbered), English line below in muted text.
4. **Lượng từ** chips with Pinyin (一门亲戚).
5. **Ví dụ**: 2–3 ranked sentences from `lib/examples/` (`rank.ts`), translations flagged "dịch máy" where they are.
6. **Từ bắt đầu bằng …** (from the same CVDICT shard, HSK words first, max 20).
7. For a single character: links "Chiết tự", "Thứ tự nét", "Tập viết" (`#c=`), and for words "Thêm vào Anki" / "Trắc nghiệm" via `lib/reader/handoff.ts` (`#words=`).
8. Footer row: "Tra thêm trên Hanzii ↗" (only the word, on click) + data credits (HSK 3.0 list, CVDICT, CC-CEDICT).
- Multi-word input (a sentence) → a short note pointing to Đọc hiểu instead of a list; keeps this page a lookup, not a second reader.
- Not found → Hán Việt per character + links to each character's lookup.
- Files: `app/tools/tra-tu/{page.tsx,layout.tsx}`, `app/en/tools/tra-tu/page.tsx`, `components/lookup/*`, pure logic in `lib/lookup/` (assembling the card from vocab + CVDICT + examples, unit-tested), `lib/links.ts` (`TOOL_GROUPS`), `nav.hints`, i18n in `vi.ts` + `en.ts`, Navbar search shortcut optional (later).
