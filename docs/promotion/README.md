# Quảng bá Hán Ngữ Studio

Bài đăng, bình luận mẫu và ảnh để giới thiệu web với giáo viên và người tự học tiếng Trung. Mọi số liệu, tính năng nhắc đến đều có thật trên web; không bịa lời khen, số người dùng.

Link chính: https://han-ngu-studio.vercel.app
Link cho giáo viên: https://han-ngu-studio.vercel.app/lesson
Link phiếu tập viết: https://han-ngu-studio.vercel.app/tools/practice-sheet
Hướng dẫn cho thầy cô (gửi kèm khi có người hỏi cách dùng): https://han-ngu-studio.vercel.app/guide

| File | Dùng khi |
|---|---|
| [bai-dang-facebook.md](bai-dang-facebook.md) | Đăng bài trong nhóm học / dạy tiếng Trung, hoặc trang cá nhân |
| [binh-luan-mau.md](binh-luan-mau.md) | Trả lời bài người khác đang hỏi tài liệu, phiếu tập viết, cách soạn bài |
| `../../public/guide/vi/` | Ảnh từng bước (cũng hiện trên trang https://han-ngu-studio.vercel.app/guide), tải về để đính kèm bài |

## Nguyên tắc

1. **Tặng trước, quảng cáo sau.** Trả lời câu hỏi bằng một file PDF/slide làm sẵn từ web, link để cuối.
2. **Một bài, một việc.** Phiếu tập viết là mũi nhọn (đã có giáo viên dùng thật); Soạn bài là bài thứ hai cho giáo viên.
3. **Không spam.** Mỗi nhóm tối đa 1 bài/tuần, đọc luật nhóm trước. Bình luận chỉ ở bài thật sự hỏi đúng việc web làm được.
4. **Xin góp ý.** Cuối bài luôn mời nhắn Zalo (link ở cuối trang web) để báo lỗi, xin tính năng.
5. **Đo.** Sau mỗi bài, xem lượt xem trong Vercel → Analytics ngày hôm đó và ghi lại 1 dòng vào bảng dưới.
