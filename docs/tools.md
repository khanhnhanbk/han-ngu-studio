## Folder structure

- `app/`: pages. `page.tsx` landing, `lesson/`, `guide/`, `licenses/`, `tools/<tool>/` (one folder per tool, routes in the Tools table), `en/…` English twins, `robots.ts`, `sitemap.ts`
- `components/`: landing-page sections at the top level (Hero, Features, ForTeachers, FAQ, Roadmap, AboutMaker, Navbar, Footer, …) and one folder per tool UI (`lesson/`, `anki/`, `quiz/`, `reader/`, `decompose/`, …)
- `lib/`: client logic, one folder per tool (`lesson/`, `anki/`, `slides/`, `reader/`, …) plus shared `i18n/`, `script/` (Giản/Phồn), `data/` (download budget), `speech/`, `seo/`, `links.ts` (`TOOL_GROUPS`, `HIDDEN_TOOLS`), `videos.ts`
- `scripts/`: data builds (`build-data.mjs`, `build-vocab-source.mjs`, `build-audio.mjs`, `fetch-ancient.mjs`, `translate-sentences.mjs`), `og/` (link-preview images), `perf/` (`pnpm perf`), `check/smoke.mjs` (browser smoke test, last step of `pnpm check`), `check/shots.mjs` (`pnpm shots`), `make-slide-templates.py`
- `public/data/`: static data files fetched at runtime
- `assets/dictionary/`: raw source data (CSV/TSV) for future data builds
- `BACKLOG.md`: open notes and work (see Working rule)
- `docs/plans/`: implementation plans (see below)
- `userguide/`: end-user guide in Vietnamese, one page per tool. Lives on GitHub only (not served, listed in `.vercelignore`).


## Details moved from CLAUDE.md code conventions

- English glossary: Phiếu tập viết = Practice sheet · Thứ tự nét = Stroke order · Chiết tự = Character breakdown · 214 bộ thủ = 214 radicals · Ngắt từ = Word segmentation · Hán Việt = Sino-Vietnamese (Hán Việt) · Tạo thẻ Anki = Anki deck builder · Trắc nghiệm = Quiz · Sắp xếp câu N+1 = N+1 sentence order · Ngũ bút = Wubi · Giản thể / Phồn thể = Simplified / Traditional · dịch máy = machine-translated · Đọc hiểu = Reader · Tra từ = Word lookup · Từ loại = Part of speech · Lượng từ = Measure words.
- **Giản thể / Phồn thể** (`lib/script/`, switch in the Navbar): pipelines and data stay Simplified. Pages convert at their boundary with `useConverter()`: `conv.toSimp(input)` into the pipeline, `conv.toShown(...)` and `createAligner` for what is shown/exported. In Giản thể mode both are the identity, so existing behaviour never changes. `t2cn` is not a no-op on Simplified text (著, 么, 乾), so `toSimp` only converts text that has non-shared Traditional characters (`SHARED_CHARS`).
- **Large downloads ask first.** Before loading data, call `confirmDownload(files)` (`lib/data/budget.ts`) with the site paths the action needs (loaders export them: `TOKENIZER_FILES`, `HANVIET_FILE`, `strokeFiles()`, `exampleFiles()`…). It prompts (`components/DownloadPrompt.tsx`) only when the not-yet-downloaded part exceeds 2 MB gzip, using `public/data/sizes.json` from `pnpm build:data`. New data files get into `sizes.json` automatically; new loaders must use `memoJson` (or call `markLoaded`).
- **English site at `/en`**: the locale comes from the URL (`localeFromPath`), Vietnamese keeps the plain paths. Every page has an `app/en/…` twin that re-exports the same page component plus English metadata (`toolMetadata` / `alternates` in `lib/i18n/metadata.ts`; Vietnamese tool folders get theirs from a small `layout.tsx`). Add both when adding a page. Tool data (Hán Việt, Vietnamese meanings, sentence translations) is not translated.

## HARD RULE 4 in full (privacy, per feature)

4. **User text is never stored or sent anywhere.** Processing happens on the user's device. Exceptions: notes the user deliberately writes (memory stories on `/tools/decompose`) the words the user marks as known in Đọc hiểu (`/tools/reader`) the characters ticked "đã học" on `/tools/path` and the lessons a teacher makes in Soạn bài (`/lesson`: name, text, word list; owner decision 2026-11-12) may be kept in that user's own browser (localStorage), never sent anywhere, with TSV export/import. The text being read in the other tools is never stored. Online browser voices: only if the user explicitly turns them on in Giọng đọc (off by default), their browser sends the single clicked word to that voice provider (Google/Microsoft); never sentences. Anki pictures (phase 4a, approved by the owner 2026-11-09): on `/tools/anki`, only after the user ticks the consent box on that visit (never remembered), each search sends one short English keyword for one word (editable, never a sentence) to the Openverse API; previews load from the pictures' own sites; the chosen picture's Openverse thumbnail is fetched once, shrunk in the browser and packed into the `.apkg` with its credit (`lib/anki/images.ts`, `components/anki/ImagePicker.tsx`). The "Tra thêm trên Hanzii" link on `/tools/lookup` is a plain link opened in a new tab: only the looked-up word, only when the user clicks it. Never embed or fetch Hanzii (or any other dictionary site). Tutorial videos: plain YouTube links opened in a new tab, all in `lib/videos.ts` (empty value hides the link); never embed a player.
   Page-view counts (owner decision 2026-11-12): Vercel Web Analytics through `components/SiteAnalytics.tsx`, which cuts the URL at `?`/`#` before sending; never add custom events that carry user text, and keep `/licenses` in step.
